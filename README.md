## Deskripsi Project 
Project ini berisi modul otomatisasi jaringan cabang virtual yang terintegrasi, meliputi identitas dasar, akses SSH (Paramiko), pemantauan SNMP (PySNMP), pembuatan pesan NETCONF XML, dan analisis data Telemetry CPU. 
 
## Struktur Folder 
- `identitas.py` - Modul identitas cabang 
- `ssh_modul.py` - Modul akses jarak jauh via SSH 
- `snmp_modul.py` - Modul pemantauan via SNMP 
- `netconf_modul.py` - Modul pembuat pesan XML NETCONF 
- `telemetry_modul.py` - Modul analisis data telemetry 
- `main.py` - Program utama integrasi laporan 
 
## Cara Menjalankan 
```bash 
python main.py 
```
